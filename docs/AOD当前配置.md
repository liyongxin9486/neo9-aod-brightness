# iQOO Neo9 AOD 当前配置与使用

2026-11-02，Neo9 AOD 4.0-schedule（29），包名 io.local.neoaod.typeguard。已覆盖安装到当前手机。

## 手机端操作

打开桌面“息屏亮度”，或在 LSPosed 中打开 Neo9 AOD 的模块设置。

1. “默认亮度”：拖动滑块，范围 20%–100%。数字越小越暗；没有时段生效时使用此值。
2. “时段 1”“时段 2”：分别打开开关，点击左右时间选择开始和结束时间，再拖动该时段的亮度滑块。
3. 点击“保存设置”。未保存的修改不会生效；保存后自动应用，不用再连接电脑或重新加载进程。

每天重复，使用手机本地时间，支持跨午夜（例如 22:00 至次日 08:00）。开始时间包含在内，结束时间不包含；启用时段起止时间不能相同。两组重叠时，时段 2 优先。结束后会使用仍在生效的另一时段，否则恢复默认亮度。

完成测试后保留默认 60%，两组时段关闭。预填时间/亮度为：时段 1，08:00–22:00、60%；时段 2，22:00–08:00、30%。预填值不是已启用的定时设置。

关闭设置软件不会停止定时；无需将其一直留在后台。时段切换由已注入的系统进程处理，只有在 AOD 图层使用时才登记下一次边界任务，没有新增常驻后台服务或逐秒轮询。

## 实际调暗方式

百分比表示息屏内容的图层显示强度，通过黑色半透明遮罩调暗，100% 取消额外调暗；不是面板亮度、尼特或耗电比例。局部与全屏共用设置，正常亮屏时不应用遮罩。

未修改面板节点、日常亮度设置、显示驱动、boot/system/vendor 分区。本轮仅重载 AOD 和 SystemUI 进程，没有整机或 zygote 重启。

## LSPosed 与设备

作用域保持：熄屏显示 com.vivo.nightpearl、系统界面 com.android.systemui。无需额外勾选系统框架。

当前设置写入权限已授权。适配设备 PD2338 / V2338A，固件 PD2338C_A_16.2.13.2.W10，熄屏显示 8.0.4.2。临时 root 与 LSPosed 必须继续有效；系统升级或框架失效后不保证可用。

保留局部样式兼容修复：局部原生样式使用类型 1，集成样式（如“搭配锁屏”）使用类型 2；全屏保持类型 2，并同步菜单选择与全屏标记。设置页保留全屏菜单，局部渲染使用对应能力。此前已验证“起源Ⅰ”和“搭配锁屏”；所有下载样式与长期稳定性未逐一验证。进入全屏时短暂黑一下的问题未在本轮处理。

## 文件与回退

- Neo9-AOD-typeguard.apk：当前已安装的模块与设置软件。
- Neo9-AOD-source.zip：完整修改源码、资源、构建脚本、测试和许可；签名密钥仍保留在本机，不放入压缩包。
- aod-settings-before.json、property-before 文件、local-aod-before-fix.json：原始备份。
- aod-rollback.sh：手动完整回退，尚未执行。

在本目录打开 PowerShell，需要完整回退时执行：

```powershell
adb -s <设备序列号> push ./aod-rollback.sh /data/local/tmp/aod-rollback.sh
adb -s <设备序列号> shell su -c 'sh /data/local/tmp/aod-rollback.sh'
```

脚本卸载模块，删除新的定时配置、旧调暗设置及新增全屏属性，恢复最初六项配置，并重载 AOD 和 SystemUI。不会整机重启或重启 zygote，不恢复时钟样式。原有 LSPosed、Zygisk 和其他模块保留。
